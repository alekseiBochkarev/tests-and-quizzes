# Sprint 2. Журнал решений

> Статус: реализовано 12.11.2026. Ветка — `master`.
>
> Документ фиксирует, что вошло в Sprint 2, какие решения приняты по ходу работы,
> чем реализация отличается от первоначального плана и что осталось за границами.

---

## 1. Что сделано

### Контент и каталог

- Добавлены модели `Category`, `Topic`, `Question`, `QuestionOption`,
  `UserInterest`, `Attempt`, `AttemptAnswer`, `QuestionProgress`, `TopicProgress`,
  `UserStats`, `DailyActivity`.
- Применены миграции `20261112083550_learning_experience` и
  `20261112083752_question_demo_flag`.
- Идемпотентный сид `npm run db:seed`: 5 разделов, 14 тем, 122 вопроса, 488
  вариантов. Повторный запуск не создаёт дубликаты и не трогает пользователей,
  попытки и прогресс.
- Демо-контент лежит в репозитории (`scripts/seed/content/*.mjs`), каждый вопрос
  помечен `Question.isDemo = true`.

### Учебный контур

- `/tests` — каталог разделов и тем, количество вопросов, прогресс, онбординг
  интересов.
- `/tests/[slug]` — тема, прогресс, выбор 10/15/20/30, запуск тренировки и
  повторения.
- `/interests` — редактирование интересов.
- `/attempts/[id]` — плеер: серверная проверка, объяснение, переход к следующему
  вопросу, продолжение после перезагрузки, выход с подтверждением.
- `/attempts/[id]/result` — счёт, процент, разбивка по темам, разбор ошибок,
  повторение.
- `/account` — «Мои результаты»: баллы/уровень, освоенные вопросы, точность,
  серия, слабые темы, изученное, история, повторение.
- `/` — персонализированная главная: «Продолжить», «Рекомендуем», «Пора
  повторить».

### Backend

- `lib/progress/*` — чистые функции mastery, выбора вопросов, рекомендаций,
  агрегатов, уровней, времени.
- `lib/attempts/service.ts` — создание попытки, ответ, завершение, прерывание,
  разбор, `countDueQuestions`.
- `lib/stats/service.ts` — главная, «Мои результаты», рекомендации, слабые темы,
  история.
- API: `/api/v1/catalog`, `/api/v1/topics/[slug]`, `/api/v1/me/interests`,
  `/api/v1/attempts`, `/api/v1/attempts/[id]`,
  `/api/v1/attempts/[id]/answers`, `/api/v1/attempts/[id]/finish`,
  `/api/v1/attempts/[id]/abandon`, `/api/v1/me/stats`, `/api/v1/me/review`.

### Проверки

- Unit: 148 тестов — mastery, интервалы, scoring, рекомендации, XP, уровни,
  серия, агрегаты тем, auth/http.
- E2E: 16 тестов — auth, guard, размер текста, axe, гостевой каталог, интересы →
  тренировка 10 → результат → «Мои результаты», прерывание и продолжение.
- `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`,
  `npm run test:e2e` — зелёные.
- CI: после `db:deploy` добавлен `db:seed`; e2e работает на `quiz_test`.

## 2. Принятые решения

| № | Решение | Почему |
|---|---|---|
| 1 | Каталог открыт без входа, тренировка требует аккаунта | Прогресс нельзя честно сохранить без пользователя; гостевой режим и merge — отдельный этап |
| 2 | Два уровня: раздел → тема; готовые выпуски `Quiz` не создаются | Тренировка от банка вопросов закрывает первый цикл без лишней сущности |
| 3 | Длина тренировки: 10/15/20/30; 30 помечена как длинная | Для 55+ важен явный финиш; 30 — осознанный выбор, а не default |
| 4 | Состав попытки фиксируется `AttemptAnswer` при старте | Правки контента не ломают начатую тренировку, `questionVersion` хранит версию |
| 5 | Правильные ответы не отдаются до ответа; проверка только на сервере | Нельзя подсмотреть ответ в браузере |
| 6 | Повторная отправка ответа идемпотентна, баллы не начисляются дважды | Защита от двойного клика и сетевых повторов |
| 7 | `finish` идемпотентен; `finish` после `abandon` возвращает `409` | Повторный запрос не ломает итог, прерванную попытку нельзя «дозавершить» |
| 8 | Прерванная попытка сохраняет XP за ответы, но не получает XP за завершение | Пользователь не теряет заработанное, но и не получает бонус за незаконченный тест |
| 9 | `score` = число верных, `maxScore` = число вопросов; XP — отдельно в `xpEarned` | Разделяем результат теста и мотивационные баллы |
| 10 | Интервалы повторения 1/3/7/16/35; 60 и 90 не реализованы | Упрощённая модель достаточна для MVP; кап 35 дней |
| 11 | Mastery 4 → 5 требует ≥ 7 дней с `lastSeenAt` | «Освоено» подтверждается отложенным ответом, а не подряд идущими кликами |
| 12 | Слабые темы — только после ≥ 5 изученных вопросов | Одна случайная ошибка не должна делать тему «слабой» |
| 13 | Точность в «Моих результатах» — после ≥ 10 ответов | Не показывать «0%» или «100%» по одному вопросу |
| 14 | `bestAccuracy` записывается только для попыток ≥ 10 вопросов | Личный рекорд не должен быть результатом короткой пробы |
| 15 | Источник истины по времени — `User.timezone`; `UserStats.timezone` — копия | Серия дней и даты считаются по локальной дате пользователя |
| 16 | Публичный рейтинг не включаем | Ядро 55+; сравнение с другими демотивирует, риск 152-ФЗ |
| 17 | Демо-контент в репозитории, а не по абсолютному пути | CI и другой разработчик получают одинаковый сид |
| 18 | Чужая попытка → `404`, не `403` | Не раскрывать существование чужих данных |
| 19 | Rate limit на старт тренировки и ответы | Защита от перебора вариантов и спама попытками |
| 20 | `Cache-Control: no-store, private` по умолчанию | Прогресс и ответы не должны кэшироваться |

## 3. Отклонения от первоначального плана

1. **Roadmap сдвинут.** По исходному ТЗ Sprint 2 — «контент и каталог», Sprint 3 —
   прохождение, Sprint 4 — прогресс. Фактически учебный контур целиком сделан в
   Sprint 2. Roadmap в `docs/02-tz.md` обновлён.
2. **Гостевой режим отложен.** В ТЗ был guest-first с merge. В реализации каталог
   открыт, но тренировка требует входа. Причина: merge прогресса — отдельная
   сложная задача, а первый цикл нужно было проверить быстрее.
3. **Нет админки и импорта через UI.** Контент загружается сидом из репозитория.
   Импорт из `forms_writer` остаётся следующим этапом.
4. **Нет готовых выпусков `Quiz`.** Тренировка работает от темы/раздела и банка
   вопросов. `Quiz`/`QuizQuestion` не создавались.
5. **Только `single_choice`.** QZ-12 закрыт частично: `true_false` и
   `image_single_choice` не реализованы.
6. **Интервалы 60/90 не реализованы.** Кап — 35 дней, как осознанное упрощение.
7. **Нет интеграционных тестов с реальной БД.** Покрытие — unit + e2e на сиде;
   интеграционные тесты отложены.
8. **Демо-контент шире ядра 55+.** В наборе есть «Гарри Поттер» и «2ГИС/карты»;
   пользователь явно предложил эти темы. Они помечены как демо и будут
   пересмотрены перед бетой.
9. **30 вопросов для 55+.** Оставлено как осознанный выбор с предупреждением
   «длинная тренировка»; по умолчанию — 10.

## 4. Известные ограничения

- Гость не может пройти тренировку: только посмотреть каталог и тему.
- Нет смены email и удаления аккаунта (осталось из Sprint 1).
- Нет «теста дня», наград, дипломов, шаринга результата.
- Нет поиска по каталогу и фильтров.
- Нет пагинации истории: показываются последние 10 завершённых попыток.
- `UserStats.timezone` дублирует `User.timezone`.
- `responseMs` в `AttemptAnswer` есть в схеме, но API пока не принимает время
  ответа; QZ-9 (время для аналитики) не закрыт.
- В демо-контенте возможны неточности; перед бетой нужен факт-чек.
- Нет отдельного экрана «Что я изучил»: блок встроен в «Мои результаты».
