# ACC-03. Cookie-баннер и аудит согласий

> **ID:** `ACC-03`
>
> **Статус:** реализовано 24.11.2026. Миграция аддитивная: в `ConsentType`
> добавлены `COOKIE_ANALYTICS` и `COOKIE_MARKETING`.
>
> **Поток:** D. ACCOUNT. Зависимостей нет. Совместимо с A, B, C, E, F.

---

## 1. Зачем

ТЗ требует cookie-баннер с категориями `necessary / analytics / marketing`
(LEG-3) и отзыв согласия (11.5). До задачи на сайте были только согласия при
регистрации: `TERMS`, `PRIVACY`, `MARKETING`. Гость не мог ни узнать про
cookie, ни выбрать категории, ни изменить решение.

Задача закрывает юридический блокер перед публичным показом:

- понятный баннер на всех страницах;
- отдельные переключатели аналитики и рекламы;
- отказ доступен так же просто, как согласие;
- выбор хранится в cookie и переживает перезагрузку;
- для вошедших пользователей выбор попадает в журнал `Consent`;
- есть Cookie-политика с категориями, списком cookie и отзывом согласия.

## 2. Продуктовые решения

| Вопрос | Решение |
|---|---|
| Категории | Необходимые, аналитика, реклама и партнёры |
| Значения по умолчанию | Только необходимые; аналитика и реклама выключены |
| Где показывать баннер | В потоке страницы под шапкой, а не поверх контента |
| Почему не всплывающий | Не перекрывает кнопки и текст — важно для 55+ |
| Как отказаться | Кнопка «Только необходимые» рядом с «Принять все» |
| Хранение выбора | Cookie `quiz_cookie_consent`, 180 дней |
| Аудит | Для вошедших — записи `Consent` по обеим категориям |
| Гость | Выбор только в cookie: нет идентификатора для журнала |
| Смена версии политики | Старый выбор недействителен, баннер спрашивает заново |
| Отзыв согласия | Кнопка на Cookie-политике открывает настройки повторно |
| Аналитика и реклама сейчас | Сервисов нет; переключатели готовят контур на будущее |
| Необходимые cookie | Отключить нельзя: без них не работают вход и размер текста |

Баннер не блокирует сайт модальным окном и не использует таймеры, тёмные
паттерны и «крестик, который соглашается за пользователя».

---

## 3. Модель согласий

`Consent` уже хранит `type`, `version`, `accepted`, `ip`, `userAgent`,
`createdAt` и допускает `userId = null`. Добавлены только новые значения enum:

- `COOKIE_ANALYTICS` — согласие на аналитические cookie;
- `COOKIE_MARKETING` — согласие на рекламные и партнёрские cookie.

При каждом сохранении для вошедшего пользователя пишутся **обе** записи: и
включение, и отказ. Это даёт историю решений, а не только текущее состояние.
Версия берётся из `LEGAL_COOKIES_VERSION`.

Гость получает только cookie: без аккаунта нельзя связать запись с человеком,
а анонимные строки засоряли бы журнал. Cookie сама по себе подтверждает выбор.

Миграция `20261124150000_cookie_consent` — только `ALTER TYPE … ADD VALUE`,
существующие согласия не меняются.

## 4. API

| Метод | Маршрут | Назначение |
|---|---|---|
| `POST` | `/api/v1/cookies/consent` | Сохранить выбор категорий |

Тело:

```json
{ "analytics": true, "marketing": false }
```

Успех: `{ "data": { "consent": { "analytics": true, "marketing": false, "version": "…", "updatedAt": "…" } } }`.

Правила:

- same-origin обязателен;
- тело — JSON до 32 КБ;
- rate-limit: 60 сохранений в час на пользователя и на IP (если `TRUST_PROXY=true`);
- cookie ставится до записи в журнал: сбой аудита не отменяет выбор;
- ошибки журнала логируются как `cookie_consent.audit_failed` без IP, UA и email;
- ответ `no-store`, cookie `SameSite=Lax`, `Secure` в production, `Path=/`.

Cookie `quiz_cookie_consent` не `httpOnly`: в ней нет секретов, а будущим
клиентским скриптам аналитики нужно уметь проверять согласие.

## 5. Интерфейс

| Место | Что видит пользователь |
|---|---|
| Баннер в layout | Заголовок, объяснение, ссылка на Cookie-политику |
| Кнопки баннера | «Только необходимые», «Принять все», «Настроить» |
| Настройки | Необходимые (включены), аналитика, реклама, «Сохранить выбор» |
| `/legal/cookies` | Категории, список cookie, сроки, отзыв согласия |
| Подвал | Ссылка «Cookie-политика» |
| Политика конфиденциальности | Ссылка на Cookie-политику |

Решения для аудитории 55+:

- баннер не всплывает поверх страницы;
- крупный текст, кнопки не ниже 56 px;
- отказ и согласие — равнодоступные действия;
- состояние категории подписано словами, а не только цветом;
- ошибка сохранения показывается текстом с `role="alert"`;
- настройки можно открыть повторно с Cookie-политики без перезагрузки.

## 6. Cookie

| Имя | Назначение | Срок | Категория |
|---|---|---|---|
| `quiz_user_id` | Сессия входа, HMAC-подпись | 30 дней | Необходимые |
| `text_size` | Выбранный размер текста | 12 месяцев | Необходимые |
| `quiz_cookie_consent` | Выбор категорий cookie | 180 дней | Необходимые |

Аналитические и рекламные cookie сейчас не устанавливаются: на сайте нет
таких сервисов. Когда появятся, они должны читать согласие из
`quiz_cookie_consent` и не загружаться без него.

## 10. Ограничения

- Реальных сервисов аналитики и рекламы нет: переключатели готовят контур.
- Нет экрана истории согласий для пользователя; история доступна в БД.
- Гость не попадает в журнал `Consent`.
- Cookie-политика — черновик до ACC-04.
- Баннер не является модальным диалогом и не удерживает фокус: страница
  остаётся доступной, пока выбор не сделан.
- Rate-limit по IP работает только при `TRUST_PROXY=true`; без флага остаётся
  бакет по пользователю.
