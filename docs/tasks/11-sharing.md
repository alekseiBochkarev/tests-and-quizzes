# GRW-01. Шаринг результата и OG-карточка

> **ID:** `GRW-01`
>
> **Статус:** реализовано 25.11.2026. Миграции нет.
>
> **Поток:** E. GROWTH. Зависимостей нет. Совместимо с A, B, C, D, F, G.

---

## 1. Зачем

ТЗ требует кнопку «Поделиться» на экране результата (RES-6): WhatsApp,
Telegram, ОК, ВКонтакте и Web Share API с запасным вариантом. До задачи
результатом нельзя было поделиться вообще: страница `/attempts/[id]/result`
закрыта логином, а ссылки в мессенджерах открывались без превью.

Задача закрывает разрыв между «человек прошёл тест» и «человек привёл
следующего»:

- с экрана результата можно отправить ссылку в мессенджер или скопировать её;
- ссылка открывается **без входа** и показывает только итог;
- в Telegram и WhatsApp у ссылки появляется нормальная карточка с процентом;
- превью есть и у остальных страниц сайта — общая карточка по умолчанию.

Публичных рейтингов, сравнения с другими и списка прошедших нет: только личный
результат, как и требуют продуктовые правила.

## 2. Продуктовые решения

| Вопрос | Решение |
|---|---|
| Что именно шарится | Личный результат: тест, процент, число верных ответов, дата |
| Ссылка на страницу результата | Не шарится: она требует входа и раскрывает разбор ошибок |
| Публичный адрес | `/share/<attemptId>/<token>` — отдельная страница только с итогом |
| Кто может открыть | Любой, у кого есть ссылка; токен и есть доступ |
| Какие попытки | Только `COMPLETED`; прерванная и незавершённая — 404 |
| Индексация поисковиками | `noindex, nofollow`; sitemap такие страницы не содержит |
| Токен | HMAC-SHA256 от id попытки, 32 символа base64url |
| Хранение токена | Нигде: считается на лету, колонки и миграции нет |
| Отзыв ссылки | Пока нет: отзыв появится вместе с настройками приватности |
| Смена `AUTH_SECRET` | Делает недействительными все ранее выданные ссылки |
| Где кнопка | На экране завершённой тренировки, сразу под карточкой баллов |
| Каналы | Системное «Поделиться», копирование, Telegram, WhatsApp, ОК, ВКонтакте |
| OG-карточка | 1200×630, название теста, процент и число верных ответов |
| Что видно в OG | То же, что на странице: без почты, имени и ответов |
| Публичный рейтинг | Нет и не планируется |

Токен в адресе — это «ссылка-доступ», как у любого «поделиться»: кто получил
ссылку, тот увидит итог. Поэтому на странице нет ничего, что стоило бы скрывать
от постороннего: ни почты, ни ответов.

## 3. Маршруты и файлы

| Что | Где |
|---|---|
| Токен, путь и абсолютная ссылка | `lib/share/token.ts` |
| Тексты результата и сообщений | `lib/share/text.ts` |
| Выборка итога без персональных данных | `lib/share/service.ts` |
| Названия теста для результата и шаринга | `lib/attempts/display.ts` |
| Публичная страница результата | `app/share/[id]/[token]/page.tsx` |
| Страница «ссылка не действует» | `app/share/[id]/[token]/not-found.tsx` |
| OG-карточка результата | `app/share/[id]/[token]/opengraph-image.tsx` |
| OG-карточка сайта по умолчанию | `app/opengraph-image.tsx` |
| Кнопки шаринга | `components/attempts/ShareResult.tsx` |
| Встраивание на результат | `app/attempts/[id]/result/page.tsx` |
| Шрифт для картинок (OFL) | `assets/fonts/GolosText-*.ttf`, `assets/fonts/OFL.txt` |

Маршрутов API нет: ссылка вычисляется на сервере при рендере результата,
отдельная мутация не нужна.

### Как строится ссылка

```
token = HMAC-SHA256(secret: AUTH_SECRET, "share:attempt:" + attemptId)
        → base64url → первые 32 символа
url   = APP_URL + "/share/" + attemptId + "/" + token
```

Префикс `share:attempt:` отделяет подпись ссылки от сессионной cookie, которая
использует тот же секрет. Страница и OG-карточка проверяют токен через
`timingSafeEqual` и отдают 404, если он не сходится.

### Почему без колонки в БД

- Нет миграции — задача не встаёт в «поезд» миграций и не конфликтует с другими.
- Нет гонки «два параллельных запроса записали разные токены».
- Ссылка стабильна: один результат — один адрес, даже после перезапуска.

Плата: нельзя отозвать конкретную ссылку и смена `AUTH_SECRET` ломает все
ранее выданные ссылки. Для MVP это приемлемо и зафиксировано здесь, чтобы
отзыв не потерялся в бэклоге.

## 4. Приватность и безопасность

- Выборка `getSharedAttempt` не запрашивает `user` вообще: только id, режим,
  счётчики, дату и названия темы/выпуска. Почту и имя невозможно вывести
  случайно — их нет в данных страницы.
- Ответы, правильные варианты и объяснения на публичную страницу не попадают.
- Неверный токен, чужая или незавершённая попытка — `404` с понятной
  страницей, без подсказок о существовании результата.
- `noindex, nofollow` в metadata и в 404; в sitemap таких адресов нет.
- Страница только читает данные: rate-limit не нужен, мутаций нет.
- После удаления аккаунта (ACC-01) попытки остаются обезличенными, поэтому
  ранее отправленная ссылка продолжает показывать только итог и ничего
  персонального.
- OG-карточка запрашивается мессенджерами без cookie и тоже проверяет токен:
  подставить произвольный id и получить чужой процент нельзя.

## 5. Тексты

- Подпись над заголовком: «Результат теста».
- Заголовок страницы: `85% — История` (для выпуска — его название).
- Строка результата: «17 из 20 верно» — без склонений, чтобы не ломаться на 1 и 21.
- Мягкая оценка: «Отличный результат» (≥ 90), «Хороший результат» (≥ 70),
  «Неплохой результат» (≥ 50), «Есть что повторить» (< 50).
- Сообщение в мессенджер: «Мой результат: «История» — 85% (17 из 20 верно).
  Проверьте себя:» — ссылка добавляется каналом, чтобы не дублироваться.
- Пояснение на странице: «Ссылка покажет только итог: тест, результат и дату.
  Почта и ответы не раскрываются».

Запрещённых слов из AGENTS.md («XP», «mastery», «streak», «квиз») в интерфейсе нет.

## 6. Доступность 55+

- Все кнопки и поля ≥ 56 px, текст 1rem и крупнее.
- Действия только по нажатию: ничего не открывается само, без таймеров.
- Системное окно «Поделиться» появляется только там, где оно есть; на
  компьютере остаются копирование и мессенджеры.
- Ссылка показана в поле только для чтения: её можно выделить и скопировать
  вручную, даже если браузер запретил буфер обмена.
- Результат копирования объявляется через `role="status"` и `aria-live`.
- Внешние ссылки открываются в новой вкладке с `rel="noopener noreferrer"`.

## 7. Тесты

Unit (`npm test`):

- `tests/unit/share/token.test.ts` — длина и алфавит токена, стабильность,
  разные попытки, испорченный токен, чужой секрет, мусор без исключений,
  сборка пути и абсолютной ссылки;
- `tests/unit/share/text.test.ts` — строка результата, границы мягких оценок,
  заголовок и описание, сообщение без ссылки, обрезка длинного названия;
- `tests/unit/attempts/display.test.ts` — приоритет названий: тест дня →
  выпуск → тема → раздел → «Тренировка».

E2E (`tests/e2e/share-result.spec.ts`):

- завершённая тренировка даёт ссылку вида `/share/<id>/<32 символа>`;
- копирование кладёт в буфер обмена именно эту ссылку;
- гость без cookie открывает страницу, видит итог, не видит почту автора;
- `meta robots` содержит `noindex`, `og:image` отдаёт `200` и `image/png`;
- подделанный токен даёт `404` и страницу «Результат не открывается»;
- у прерванной тренировки блока «Поделиться результатом» нет.

## 9. Откат

Миграции нет. Чтобы отключить шаринг, достаточно убрать блок `ShareResult`
с экрана результата: страницы `/share/*` начнут отдавать 404, данные и
настройки не затрагиваются. `AUTH_SECRET` при откате не меняется.
